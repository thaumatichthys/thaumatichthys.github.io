About

Hello! My name is Max Xiang and I am currently an undergraduate student at the University of British Columbia. I have an interest in electronic design and I am studying electronic engineering, but my interests span other subjects such as mechanical design, 3D printing, insects, and more!

I made this site in the last year of high school to document some of my projects. I do this mostly to remind myself of how I did them, in case I need to revisit them in the future. I also hope to provide a resource for learning how to do certain things, or how various things work. Note that this is not an exhaustive list; I often only write projects that I actually complete, which is probably like around 50% of all the ones I attempt. If you see any errors of have questions, please feel free to contact me.

In case you're curious, here is a list of the tools I am familiar with:

Tool Description Familiarity Used since: Remarks
Software Programs
KiCAD PCB Design Software 5/5 2023 I switched to KiCAD from EasyEDA in 2023 since I wanted an offline, locally running program. It's also free.
Altium PCB Design Software 4/5 2024 I use it for more complex projects as well as certain school related projects. It is good for high speed stuff.
EasyEDA PCB Design Software 5/5 2018 This was the first PCB design software I learned. I used it to make some projects such as a class D amplifier board back in grade 8, as well as countless others. I eventually switched to using KiCAD since this one runs online, and sometimes projects get corrupted.
LTSpice Electronic SPICE simulator 5/5 2019 A popular free electronic circuit simulator. The first time I used it was right before the COVID lockdown, simulating an LED driver based on the TL494.
Solidworks 3D Parametric CAD tool 4/5 2026 I learned Solidworks for my third year project course, ELEC391. Although I have not used it before this, I found it to be quite similar to Fusion 360, and I found it very intuitive. I especially like the way that assemblies are done, and I now prefer it over Fusion.
Fusion 360 3D Parametric CAD tool 5/5 2019 When I first started 3D printing stuff in 2018, I used Tinkercad, but I found that it was kind of terrible so I learned Fusion with an education license. I used it to design basically everything I printed up until 2026, when I switched to mostly Solidworks for its better performance in my opinion.
ANSYS HFSS EM Simulator 3/5 2025 I used this to simulate some cavity filters, as well as transmission line models for UHF and X band frequencies.
Cadence AWR (MWO) RF Circuit Simulator 3/5 2025 Designed an X band oscillator using an SiGe HBT.
Davinci Resolve Video Editor 3/5 2020 I used this software to edit some basic youtube videos starting back in middle school.
Arduino Microcontroller learning platform 5/5 2019 Similarly to most people (I presume at least), I started learning embedded programming with the Arduino nano. It is still not bad for simple projects.
Quartus II Intel / Altera FPGA IDE 4/5 2024 Used to program Altera FPGAs using SystemVerilog in several courses.
ModelSim HDL simulator 4/5 2024 Used to simulate / verify HDL programs before compiling in Quartus.
Programming Languages
Python Scripting language 4/5 2020 I use Python to do basically everything I don't want to plug into a calculator! I started back in 2020 to try to do some audio effects using FFT, but now I use it for basically everything.
Embedded C Firmware for microcontrollers 4/5 2019 I generally program microcontrollers using C. Sometimes I will use C++, but I find that often, I don't actually use the C++ features, so having it is just a waste of overhead in my opinion. For most simple things, using structs is good enough to pretend to be OOP for me.
MATLAB Math centred scripting language 2/5 2024 I generally use this for school assignments. It is good for some things, but the locked-down-ness is a bit annoying to me. I also don't like how it runs so slow.
SystemVerilog Hardware Description Language 3/5 2024 This is the HDL that I know. It is used for programming FPGAs, and I think SystemVerilog is pretty good and intuitive for that purpose. I use it alongside Quartus and Modelsim.
8051 Assembly Assembly language for Intel 8051 3/5 2024 I learned to be proficient in 8051 ASM in my second year project course. It was a bit painful to learn at first but I eventually became good enough at it to write some basic programs including a 12 channel DDS synthesizer + music note player, which takes a custom ROM format which is generated from a MIDI file using a python script. Also programmed a reflow oven controller and alarm clock.
ARMv7 Assembly Assembly language for ARMv7 1/5 2024 I learned this for my computing systems I class. I am mostly putting this here for completeness - I haven't actually used this for any projects, but I do know how the basic instructions work.
Hardware / Lab tools
Oscilloscope UNI-T UTD2052 5/5 2018 I kind of impulse bought an entry level oscilloscope while walking around in an electronics market in Beijing, China. I still use it to this day - for anything that has waveforms!
Bench Power Supply RIDEN RD6018, various others 5/5 2024 Surprisingly I actually never got my own bench supply until last year. Before, I was kind of just using USB power, 9V batteries, and sometimes a 4 button LiPo charger. I am glad that I got an actual one now though.
Signal Generator RIGOL DG1022 5/5 2024 I used it mostly for convenience in testing various stuff in my second year laboratory, in place of generating the signals with a microcontroller pin or something.
Spectrum Analyzer HP8596E, DSA815, R&S FPC1500 5/5 2024 I used these to test various RF circuits (transmitters and oscillators) including a CC1110 transceiver, homemade oscillators, a DIY 10 GHz schottky ring mixer, an LMX2592 PLL board, etc. I am most familiar with the old HP8596E - it is old but very capable!
Vector Network Analyzer Keysight P5024B, Agilent N9912A, LiteVNA 4/5 2024 These are used to characterise passive RF circuits such as filters, attenuators, switches, etc. I used them to characterise various DIY filters, including several copper tape "microstrip" filters, an 8 GHz microwave cavity, etc. On average I am 4/5 confident in using these, but for the LiteVNA I think 5/5 is appropriate since I use it very often.
Prototyping / Assembly
Soldering Iron Soldering various things 5/5 2016 I have been soldering stuff since elementary school. I can solder fine pitched THT, and SMT down to 0402. I have not attempted to solder 0201 yet though.
Reflow soldering Soldering SMT PCBs 5/5 2023 I built my first reflow oven in grade 12, using a toaster oven from Walmart. Manual solder paste + placement using tweezers + reflow is now my favourite assembly method, and I will not hand solder any SMT boards unless I really need to for some reason. Sometimes when I don't have access to the oven, I will also reflow on the kitchen stove (using lead free solder of course).
Hot Air SMT Rework 2/5 2024 Perhaps this is something I should work on, I have only really reworked a PCB one or two times using hot air.
Toner transfer method DIY PCB fabrication 4/5 2023 I have printed several of my own PCBs using a laser printer, transferred onto copper clad PCB and then etched in ferric chloride. It is quite tedious to get the transfer right, but it can be touched up with a sharpie. This method is overall kind of painful to get right, but for small simple PCBs, it is much faster than ordering from a manufacturer, since you can go from design to produced in under an hour.
